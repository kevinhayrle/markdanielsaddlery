# Mark Daniel Saddlery — Frontend

This is the frontend repository for *Mark Daniel Saddlery*, a luxury equestrian e-commerce platform engineered for global customers. Built using HTML, CSS, and Vanilla JavaScript, this frontend delivers a premium, high-performance shopping experience with structured product presentation, international checkout integration, and scalable UI architecture.

# Core Responsibilities

- Dynamic product rendering via backend APIs
- Category-based browsing and structured filtering
- Detailed product specification display
- Multi-image product gallery system
- Real-time inventory visibility
- International payment gateway integration
- Secure checkout workflow
- Order confirmation and tracking interface
- Admin product management interface

# Key Features

## Product System

- Dynamic product loading via Fetch API
- Multiple product image rendering
- Structured specification display
- Category-based filtering
- Optimized product layout for luxury branding

## Cart System

- LocalStorage-based cart management
- Quantity adjustment support
- Real-time total price calculation
- Seamless checkout transition

## Checkout

- International payment gateway integration
- Secure payment processing
- Order verification and confirmation system

# Technologies Used

- HTML5

# Security & Best Practices

- No sensitive payment data stored on frontend
- Secure authentication for admin dashboard
- Clean API integration via centralized config file
- Structured semantic HTML for accessibility
- Performance-optimized assets and layouts

# Deployment

Frontend can be deployed on any static hosting provider:

- Netlify
- Vercel
- GitHub Pages
- Traditional hosting (cPanel / VPS)

## Deployment Steps

- Push repository to GitHub
- Connect hosting provider
- Configure API base URL in config file
- Ensure production domain is set in SEO meta tags
- Deploy
